# Learnify – Online Education Platform

Learnify is a modern, responsive online education platform built with React.js, Vite, Tailwind CSS, and JavaScript.

The project provides a professional learning experience with course browsing, course details, authentication screens, enrollment flow, dashboard UI, instructors, testimonials, and responsive layouts.

## 🚀 Features

### 🏠 Home Page

- Modern hero section
- Learning-focused hero video
- Explore Courses CTA
- Browse Learning CTA
- Learner statistics
- Popular courses
- Why Learnify section
- Expert instructors
- Learner testimonials
- Call-to-action section
- Smooth navigation
- Responsive design

### 📚 Courses

- Course listing
- Course cards
- Course categories
- Search functionality
- Course ratings
- Course duration
- Student count

- Course levels
- Course details navigation

### 📖 Course Details

### 👨‍🎓 Student Dashboard

- Enrolled courses

### 🔐 Authentication UI

- Login page
